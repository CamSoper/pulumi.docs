> [!TIP]
> **Summary:** This PR appends a "Choosing a secrets backend" section to the IaC secrets concept page — a comparison of six ESC-supported secrets providers plus guidance on policy enforcement, CI rollout, and migration, in the same explanatory register as the rest of the page. The blocking problem is product naming: the new prose leans on names Pulumi retired — Pulumi Service, CrossGuard, Policy Violations, Pulumi Insights (and its "Insights account/scan/supergraph/resources" vocabulary), and Pulumi Copilot — which sends a reader searching the docs for things that no longer exist under those names. Two substantive accuracy issues sit underneath that: policy packs are described as TypeScript/JavaScript-only when Python is also supported, and CyberArk Conjur is presented as an ESC backend without a provider we could find. Fact verification, terminology and spelling linting, a frontmatter sweep, and a temporal-trigger sweep all ran; no code examples or build-affecting changes are in scope.
